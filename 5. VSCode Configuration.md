## STEP 5: SETTING UP VS CODE TO EDIT CODE ON THE PI

> **What you'll do:** Install Visual Studio Code on your laptop and connect it to the Raspberry Pi so you can edit code, run commands, and see files — all from your laptop, as if the Pi's files were on your own computer.

> **What you need for this step:**
> - Your laptop
> - VS Code installed ([download here](https://code.visualstudio.com/) if you haven't already)
> - The Pi powered on and connected to WiFi

> **Why VS Code?** You *could* edit files on the Pi using the terminal (with `nano` or `vim`), but VS Code gives you a proper code editor with syntax highlighting, autocomplete, file browsing, and an integrated terminal. It makes development much faster and easier.

---

### Part A: Install the Remote-SSH Extension

> **What is Remote-SSH?** It's a VS Code extension that lets VS Code connect to the Pi over SSH. When connected, VS Code shows the Pi's files in its file explorer, and its terminal runs commands on the Pi — but the VS Code window itself is on your laptop.

1. **Open VS Code** on your laptop

2. **Open the Extensions panel:**
   - Click the **Extensions icon** on the left sidebar (it looks like 4 squares)
   - Or press `Ctrl+Shift+X`

3. **Search for "Remote - SSH":**
   - Type `Remote - SSH` in the search box
   - Find the one by **Microsoft** (it should be the first result)
   - Click **Install**

4. **Wait** for the installation to complete (takes a few seconds)

---

### Part B: Connect VS Code to the Raspberry Pi

5. **Open the Command Palette:**
   - Press `Ctrl+Shift+P` (this opens a search bar at the top of VS Code)

6. **Type:** `Remote-SSH: Connect to Host...` and select it from the dropdown

7. **Type the SSH address:** `pi@trio.local` and press **Enter**

   > If this is your first time connecting, VS Code may ask:
   > - **Select platform:** Choose **Linux** (because the Pi runs Linux)
   > - **Continue?** Click **Continue** when asked about the fingerprint

8. **Enter the password:** `raspberrypi`

9. **Wait 1–2 minutes** — VS Code is installing its server on the Pi (this only happens the first time). You'll see a progress indicator in the bottom-left corner.

10. **You'll know you're connected when** the bottom-left corner of VS Code shows:
    ```
    SSH: trio.local
    ```
    > This means VS Code is now connected to the Pi. Everything you do in this window happens on the Pi.

---

### Part C: Open the Project Folder

11. **Click** `File → Open Folder` (from the top menu)

12. **Type** `/home/pi/thesis` in the path box and click **OK**

    > You should now see the project files in the left sidebar (Explorer panel):
    > ```
    > thesis
    > ├── config/
    > ├── data/
    > ├── logs/
    > ├── models/
    > ├── src/
    > ├── requirements.txt
    > └── setup.sh
    > ```

13. If VS Code asks **"Do you trust the authors of the files in this folder?"** — click **Yes, I trust the authors**

---

### Part D: Select the Python Interpreter

> **Why do this?** VS Code needs to know which Python to use. We want it to use the one inside our virtual environment (`venv/`), not the system Python.

14. **Press** `Ctrl+Shift+P` to open the Command Palette

15. **Type:** `Python: Select Interpreter` and select it

16. **Choose:** `/home/pi/thesis/venv/bin/python`
    - It might show as `Python 3.x.x ('venv': venv)`
    - If you don't see it, click **"Enter interpreter path..."** and type: `/home/pi/thesis/venv/bin/python`

---

### Part E: Install Recommended Extensions (On the Pi)

> When VS Code is connected to the Pi via SSH, some extensions need to be installed **on the Pi side** too (not just your laptop).

17. **Open Extensions** (`Ctrl+Shift+X`) and install these **on the SSH host**:
    - **Python** (by Microsoft) — Python language support
    - **Pylance** (by Microsoft) — Better Python autocomplete

    > You'll see an "Install in SSH: trio.local" button — click that, not the regular Install button.

---

### Part F: Open the Terminal Inside VS Code

18. **Press** `` Ctrl+` `` (the backtick key, usually below `Esc`) to open the integrated terminal

    > This terminal is running **on the Pi**, not on your laptop! You can run all the same commands here as in SSH.

19. **Activate the virtual environment:**
    ```bash
    cd ~/thesis && source venv/bin/activate
    ```

    > You should see `(venv)` appear at the beginning of the prompt line.

---

### ✅ Checkpoint

You've now:
- ✅ Installed the Remote-SSH extension in VS Code
- ✅ Connected VS Code to the Pi
- ✅ Opened the project folder
- ✅ Selected the correct Python interpreter
- ✅ Opened a terminal that runs on the Pi

**From now on**, you can edit any file on the Pi by clicking on it in VS Code's file explorer. Changes are saved directly to the Pi.

---

### What If WiFi Changes and You Lose Connection?

This is **normal** and nothing is lost:

1. Your code and files are safe on the Pi's SD card — they don't disappear when WiFi drops
2. Move to a location with one of your pre-configured WiFi networks (from Step 2)
3. Wait ~30 seconds for the Pi to auto-connect
4. In VS Code, either:
   - Click **"Reconnect"** if prompted, or
   - Press `Ctrl+Shift+P` → `Remote-SSH: Connect to Host...` → `pi@trio.local` again
5. You'll be right back where you left off
