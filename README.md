# Thesis-Configuration

How to configure Raspberry Pi 5 for thesis "NB-IoT Enabled Rice Monitoring System Using Raspberry Pi V5 and Computer Vision"

# Materials Needed
1. Laptop
2. Raspberry Pi V5
3. Power Supply
4. Micro SD Card (Minimum 32 GB)
5. SD Card Reader
6. USB Web Camera
7. Soil Moisture Sensor
8. Temperature and Humidity Sensor
9. NB-IoT Module
10. NB-IoT Sim

# Software Needed
1. Raspberry Pi Imager
2. Command Prompt/Powershell
3. Visual Studio Code
